## Notes

- Upstream checkout: a `dsh-routing-suite` directory (read-only reference). The
  differential tests skip with an explicit message when it is not reachable;
  set `DSH_ROUTING_SUITE` to the upstream
  `preset/router-standard/router-core.mjs` to enable them anywhere.
- `marketplace.json` is generated by `scripts/install.mjs` at install time, not
  committed — it carries an absolute path to this checkout.
- Installed copies live at `~/.zcode/cli/plugins/marketplaces/local-dsh-router/`
  and `~/.zcode/cli/plugins/cache/local-dsh-router/dsh-router/<version>/`. Re-run
  `node scripts/install.mjs` after a source change, then open a new session.
- Runtime state is outside the repo, at
  `~/.zcode/cli/plugins/data/dsh-router@local-dsh-router/` (the client passes this
  as `ZCODE_PLUGIN_DATA` when it runs a hook).
