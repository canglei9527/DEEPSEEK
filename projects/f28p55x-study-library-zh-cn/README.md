# TI F28P55x 开发学习资料（中文翻译）

本资料包优先收录有助于 F28P55x 器件开发与学习的官方技术文档：技术参考手册、外设对照、器件规格与勘误、C2000 软件和启动/Flash、开发板、功能安全/计量、安全引导、NPU，以及 CLB 工具与工程案例。产品宣传页、证书和与当前开发无关的通用资料未纳入。

中英对照：00–19 号资料的英文原版和中文译本已集中在[中英对照文件夹](中英对照/README.md)，可按相同编号对照阅读。

当前状态：F28P55x 专项学习资料 00–19 的中文译本已完成并核验。以下资料均来自 TI 官方发布。

译文由本任务中的模型结合段落上下文和统一术语表逐段撰写，不调用第三方翻译 API；目录、书签、表格和版面逐份检查，发现漏译或不顺处会重译、修整。模型译文仍需对照 TI 原文核实安全要求、电气参数、寄存器与时序数据。

## 建议阅读顺序

1. 先用 F28P55x 技术参考手册（ID 00）查外设和寄存器；外设参考指南（ID 17）可快速确认各 C2000 器件的外设差异，再对照数据手册与芯片勘误（ID 01–02）。
2. C2000 开发入门与软件指南（ID 08、10）；按启动需求继续阅读引导加载和 Flash API（ID 09、05）。
3. 使用哪块板卡就看对应硬件指南（ID 06 或 07）。
4. 按项目选择功能安全、计量、数字电源、安全引导或 NPU 资料（ID 03、04、11、18、19）。
5. 需要用 CLB 实现逻辑时再读 ID 12–16。

### 技术参考手册章节导读

- 通用基础：第 2 章 C28x 处理器 → 第 3 章系统控制与中断 → 第 4 章 ROM 代码与外设引导 → 第 5 章双区代码安全模块（DCSM）→ 第 6 章 Flash。
- 控制与电源：第 10 章 GPIO、第 11 章 XBAR、第 14–19 章模拟子系统/ADC/DAC/CMPSS/PGA/ePWM；需要可编程逻辑时继续看第 30 章 CLB。
- 通信外设：按项目使用的接口查阅第 22–29 章（SPI、SCI、USB、FSI、I2C、PMBus、MCAN、LIN）。
- NPU 应用：查看第 8 章，并配合 ID 19 NPU 指南。

### 结合当前 F28P550 固件的优先查阅路径

当前工程使用 LIN-A 的 SCI 兼容模式配合 DMA 作为主联仿串口，SCI-B 保持 FIFO 中断和 RS-485 收发控制。排查这条数据链路时，建议按下面顺序查阅：

1. 先看 ID 01 数据手册的引脚复用、电气特性和 DMA 可访问性，再看 ID 02 勘误，确认所用硅版本的限制。
2. 在 ID 00 技术参考手册中依次查第 3 章“系统控制与中断”、第 10 章“通用输入/输出”、第 12 章“直接存储器访问”、第 23 章“串行通信接口”和第 29 章“局域互连网络”。重点对照 GPIO28/29 的 LIN-A 复用、LIN 的 UART 兼容模式和 DMA 请求/中断，以及 SCI-B 的 FIFO、中断和引脚复用。
3. 用 ID 17 外设参考指南核对 F28P55x 外设可用情况；寄存器定义和操作细节仍以 TRM 与器件勘误为准。
4. 需要改引导或片上 Flash 更新流程时，再读 ID 09 引导加载指南和 ID 05 Flash API 指南；只有实施加密/认证启动时才需要继续读 ID 18。

若工作内容转向电机/电源控制，再按实际外设补读 TRM 中的 ePWM、ADC、CMPSS 等章节和 ID 11 DigitalPower 资料。ID 06、07 仅适用于对应的 TI LaunchPad 或 ControlCARD；使用第三方 F28P550 板卡时，应优先核对该板的原理图和硬件手册。CLB（ID 12–16）、NPU（ID 19）和计量（ID 04）按项目功能选读即可。

## 术语和阅读提示

- **ID 01 数据手册原文备注：**TI 官方版本将 32 位浮点格式描述为“双精度”，并写明 Flash 总容量为 1084 KB；同一手册列出的 4 × 256 KB 加 64 KB 合计为 1088 KB。译文保留原文表述和数值，未自行修订；请结合具体订购型号及最新版 TI 文件核实。

- **ID 00 技术参考手册校验提示：**结构校验通过（3855 页、1611 条书签）。翻译器另记录 1970 条 token 差异提示（821 条数值/保护 token、1149 条引用 token）；这些提示不属于结构错误，使用前请重点对照 TI 原文复核数值、寄存器标识和引用。

- 统一译名见[术语表](术语表.md)。
- 已统一使用同一术语表，保留器件型号、寄存器/API 名、代码标识、单位与数值。正文按中文技术文档习惯表达。
- 图内嵌文字、公式图和原 PDF 的扫描图不会被 OCR 改写；如需核对图内标注，请对照 TI 原文。
- C2000 软件指南 v1.5 与 DigitalPower SDK 入门指南 Rev B (2020) 的工具版本内容较旧，安装界面和流程请按当前 TI 软件版本核实。
- 翻译用于开发学习与查阅，不替代 TI 原文中的安全、器件规格和勘误要求。
